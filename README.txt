РОМАНТИЧЕСКИЙ САЙТ-ПРЕДЛОЖЕНИЕ ДЛЯ НАДИ

Эта версия посвящена не только пяти месяцам, но и мечте о совместной жизни и браке.
Главный вопрос: «Малышка, станешь моей женой?»
Музыки нет. Пять присланных фотографий встроены в папку assets.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создай новый репозиторий на GitHub.
2. Загрузи index.html, README.txt и папку assets в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch, ветку main и папку /(root), затем Save.
5. После публикации GitHub покажет ссылку в разделе Pages.

ФОТОГРАФИИ
Для замены оставь имена файлов assets/hero.webp и assets/nadya-1.webp ... nadya-5.webp.

ИЗМЕНЕНИЕ ТЕКСТА
Все надписи и письмо находятся в index.html. Открой файл в любом текстовом редакторе.
